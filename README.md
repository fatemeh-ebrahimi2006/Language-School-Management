# سیستم مدیریت آموزشگاه زبان
## Language School Management System

### معرفی پروژه
این پروژه یک نرم‌افزار مدیریت آموزشگاه زبان است که با زبان برنامه‌نویسی پایتون (Python) طراحی شده است.

هدف از ساخت این برنامه، مدیریت دوره‌های آموزشی، اطلاعات معلمان، ثبت‌نام دانش‌آموزان و نگهداری سوابق ثبت‌نام است.

رابط گرافیکی برنامه با استفاده از کتابخانه CustomTkinter طراحی شده و اطلاعات ثبت‌نام‌ها در پایگاه داده SQLite ذخیره می‌شوند.

### امکانات برنامه

- نمایش زبان‌های انگلیسی، ترکی استانبولی و اسپانیایی
- ارائه دوره‌های آموزشی در سه سطح مبتدی، متوسط و پیشرفته
- نمایش اطلاعات دوره‌ها و معلم مربوط به هر دوره
- نمایش شهریه هر دوره
- ثبت‌نام دانش‌آموزان در دوره‌های آموزشی
- دریافت و اعتبارسنجی نام، نام خانوادگی، شماره موبایل و کد ملی
- جلوگیری از ثبت‌نام تکراری یک دانش‌آموز در یک دوره
- ذخیره اطلاعات ثبت‌نام در پایگاه داده SQLite
- مشاهده سوابق ثبت‌نام‌های قبلی
- نمایش پیام‌های موفقیت و خطا به کاربر

### فناوری‌ها و کتابخانه‌های استفاده‌شده

- Python
- CustomTkinter برای طراحی رابط گرافیکی
- SQLite برای ذخیره و مدیریت اطلاعات
- PersianTools برای اعتبارسنجی اطلاعات ایرانی
- Object-Oriented Programming (برنامه‌نویسی شیءگرا)

### پیش‌نیازهای اجرای برنامه

برای اجرای پروژه به موارد زیر نیاز است:

- نصب Python
- نصب کتابخانه‌های موردنیاز پروژه
- استفاده از محیط توسعه PyCharm یا محیط مشابه

### نصب کتابخانه‌ها

ابتدا ترمینال را در پوشه اصلی پروژه باز کنید و دستور زیر را اجرا کنید:

```bash
pip install -r requirements.txt
```

### اجرای برنامه

برای اجرای نرم‌افزار، فایل اصلی پروژه را اجرا کنید:

```bash
python main.py
```

### پایگاه داده

این برنامه از SQLite برای ذخیره اطلاعات ثبت‌نام دانش‌آموزان استفاده می‌کند.

فایل پایگاه داده به‌صورت خودکار در پوشه `data_access` ایجاد می‌شود و اطلاعات ثبت‌نام‌ها پس از بستن و اجرای مجدد برنامه نیز باقی می‌مانند.

اطلاعات اولیه معلمان و دوره‌ها در نسخه فعلی به‌صورت نمونه در برنامه تعریف شده‌اند.

### آزمایش و بررسی برنامه

برای بررسی عملکرد بخش‌های مختلف پروژه، فایل‌های آزمایشی در پوشه `test` قرار گرفته‌اند.

این آزمایش‌ها بخش‌هایی مانند مدیریت دوره‌ها، ثبت‌نام دانش‌آموزان و اعتبارسنجی اطلاعات را بررسی می‌کنند.
